## PLM 模板识别结论

PLM 尺码表导出可能是长表，也可能是宽表；本轮实现同时兼容两种形态：

- 长表核心列：`款号`、`测量点`、`尺码`、`尺码值`
- 宽表核心列：`款号`、`测量点`、`080`、`090`、`100` 等尺码列
- 尺码统一归一为深绘风格，如 `80/`、`080`、`80` 均归一为 `80cm`
- 生成到深绘的 `value_json` 形态：

```json
{
  "title": "肩宽,袖长,袖口,胸围,衣长,下摆围",
  "80cm": "26.5,24.5,8.4,66,38,80"
}
```

| 大腿围 | 1/2脾围 |
| 袖笼围 | 1/2夹圈（弯量）、1/2夹圈弯量、1/2夹直（边至边量）背心 |

AI 推荐与人工审核的落地边界：

- AI 只能从真实 PLM 测量点里选择，不能编造测量点。
- 人工保存后的映射落到 `product_archive_size_chart_mapping`。
- 点击「应用到草稿」时，系统会使用审核通过的映射重建草稿尺码表字段。
