# 官方类目优先：实现与回归结果

2026-09-21。依据最新业务指令：“官方和其他渠道类目不一致的时候，以官方类目为准”。

本次已修改本地鞋品推荐逻辑；未提交、推送、部署或修改线上草稿。此前回归方案中“跨渠道不同一律转待确认”的建议已由本规则取代。服装等非鞋分支保持原逻辑。

## 规则

1. 鞋品有官方类目时，只从其对应鞋类中推荐。唯品、抖音、上市计划品类/小类不得覆盖官方类目，也不会仅因渠道差异触发待确认。
2. 补齐官方皮靴→深绘靴子、儿童户外鞋→户外鞋、儿童棉拖鞋→棉拖鞋、儿童凉拖鞋→拖鞋、婴儿步前鞋/袜鞋→婴儿步前鞋等名称映射。匹配末级名称，不从父路径“鞋靴箱包”命中包包。
3. 官方运动鞋就推荐运动鞋，不因唯品学步鞋、板鞋或计划户外鞋而跨类切换；官方学步鞋同样不被板鞋覆盖。
4. 缺少官方类目时保留原有其他来源回退逻辑。此次不把缺官方的样本统一转人工，也不宣称宽泛休闲鞋证据已得到补充。
5. 同一官方字段有多个不同鞋类，或官方对应深绘类目不存在，仍待确认；不得改用其他渠道解冲突。官方写法不同但映射到同一类别不误报冲突。
6. 必需平台和已有 SKU 尺码校验继续有效，官方匹配不能绕过。直接鞋类不可用时，仅在相同官方鞋类中尝试合法性别分支。
7. 推荐不同于草稿已选类目时保留 `appliedTrade`，进入确认流程；保留人工调整状态及确认时间，不自动替换历史草稿。
